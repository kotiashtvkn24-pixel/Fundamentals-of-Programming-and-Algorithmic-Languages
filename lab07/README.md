# Лабораторна робота №7

**Котяш Тарас, КН-3/1**

Тема: Узагальнені алгоритми, налаштовані делегатом.

Запуск: `dotnet run --project Lab07.csproj`.

## 1. Filter
Відбір чисел ≤ 0, слів із дефісом та студентів із балами 60–89 включно. Тіло Filter між застосуваннями змінено 0 разів.

## 2. Map
Числа перетворюються на знак, слова — на першу літеру, студенти — на бал. Додатково показано композицію Filter + Map.

## 3. Aggregate

### Сума
- Стан: поточна сума (int).
- Старт: 0.
- Крок: s + x.

### Добуток
- Стан: поточний добуток (BigInteger, щоб уникнути переповнення).
- Старт: 1.
- Крок: s * x.

### Максимум
- Стан: найбільше число або null (int?).
- Старт: null.
- Крок: якщо стан null або новий елемент більший, зберегти новий елемент; інакше залишити стан.

### Середнє арифметичне
- Стан: кортеж (sum, count).
- Старт: (0, 0).
- Крок: (sum + x, count + 1).

Після одного проходу ділимо суму на кількість. Для порожнього набору середнє не визначене.

## 4. GroupBy
Один алгоритм групує студентів за групою, першою літерою прізвища, діапазоном балів, а слова — за довжиною. Ключ визначає делегат.

## 5. Захоплення змінних
Фактичний вивід (.NET SDK 8.0.428):

```text
До зміни: True
Після зміни: False
for: 3, 3, 3
foreach: 0, 1, 2
Виправлений for: 0, 1, 2
```

1. Лямбда захоплює змінну threshold, а не копію її значення. Після зміни порога на 1000 перевірка числа 24 повертає False.
2. У for всі делегати захоплюють одну змінну i. Після завершення циклу вона дорівнює 3.
3. У сучасному C# foreach створює окрему змінну для кожної ітерації. Тому делегати повертають 0, 1, 2.

Виправлення for: створити локальну копію `int copy = i` у тілі циклу та захоплювати її.

## 6. Висновок
1. Для трьох критеріїв і трьох типів за окремої реалізації кожної комбінації потрібно до дев'яти функцій (або три для одного рядка варіанта). Тут достатньо одного Filter та відповідних делегатів. Це усуває дублювання циклів.
2. У завданні перевірки балів студентів узагальнення функції Band було б зайвим: вона працює лише з цілими балами та конкретними межами оцінювання. Додавання типових параметрів без інших сценаріїв використання лише ускладнило б код.
